# Numerical experiments for McKean–Vlasov SDEs

## Paper

**Long time strong convergence analysis of one-step methods
for McKean–Vlasov SDEs with superlinear growth coefficients**

Taiyuan Liu, Yaozhong Hu and Siqing Gan

## Code

[Browse the source code](https://github.com/taiyuanUA/mv-sde-long-time)

## Numerical experiments

- Long-time propagation of chaos.
- Error saturation and terminal-time dependence.
- Strong convergence with additive noise.
- Strong convergence with multiplicative noise.
- Vlasov interaction with measure-dependent diffusion.
